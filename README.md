# PassyCoreMSALPackage

Binary Swift package for the Passy Apple SDK. Requires iOS 17 or later. Mac Catalyst and watchOS are not supported.

Add https://github.com/PassySRL/PassyCoreMSALPackage.git to Xcode and select the product declared in Package.swift.
Release 1.0.111 contains the XCFramework files attached to the matching GitHub Release.
